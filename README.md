# Der Heimkehrer

An interactive beer-mug story: Ben drives his Kia EV6 from Munich to Budaörs to finally open the box of twenty Augustiner Festbier.

**Play:** open `index.html`, or visit the GitHub Pages site.

- Desktop: click and tap; **Space** honks, **B** thinks of the beer.
- Mobile: works in landscape. On a portrait phone the scene turns sideways automatically, so hold the phone sideways.

It's a static `index.html` plus one image (`ev6.webp`), with no build step.
